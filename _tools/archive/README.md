# 历史迁移脚本（已归档）

这里放的是**一次性**的内容迁移脚本，只在整理文案的特定阶段跑过一次，跑完就不再维护，
留在这里是为了能追溯某条提示词当时为什么写成现在这样。

| 文件 | 作用 |
| --- | --- |
| `migrate.py` | 第一批内容优化迁移 |
| `migrate2.py` | 语义级合并：把重复 / 近重复条目合并成一条 |
| `migrate3.py` | 文案层重写 |
| `migrate4.py` | 第二批文案重写：拆长句、分长串、补结构 |
| `migrate5.py` | 脱敏与通用化 |
| `migrate6.py` | 曾为每条补 `<!-- n: -->` 说明字段（该字段已废弃） |
| `migrate7.py` | 把废弃的 `<!-- n: -->` 换成 `<!-- s: 简洁表达 -->` |
| `restructure_v2.py` | 2026-11-16 的分类重排与条目合并 |
| `check_len.py` | 改写后自检：字数、句数、空泛词、铺垫语、顿号连排、简洁版长度 |
| `readme_counts.py` | 按 `src/prompts/` 实际内容重生成根 README 的规模行与分类表格 |
| `restyle_spec.md` | 2026-11-16 文案改写规范 |
| `round4.py` / `round4_fix.py` / `round4_readme.py` | 第四轮：合并 6 条 + 补 26 条 + 22 处改写与 README 同步 |
| `round5.py` / `round6.py` | 第五、六轮：补 14 条 / 16 处复审修正 |
| `round9_direct.py` / `round9b_direct.py` | 第九轮 2026-11-17：全库文案「直接表达」收口（去公文腔） |
| `round10_noph_a.py` / `round10_noph_b.py` | 第十轮 2026-11-17：全库去占位符（412→0） |
| `round11_reorder.py` | 第十一轮 2026-11-17：分类生命周期重排与类内叙事重排（幂等，锚点机制） |
| `round12_narrative.py` | 第十二轮 2026-11-17：并行增补后的类内叙事修正 |
| `merged_absorbed.md` | 被并入其它条目的原文存档（重写时吸收其独有要点） |
| `coverage.py` | 按 5 字 n-gram 重合率判断覆盖；库内条目统一改写后该信号噪声过大，已归档备查 |

**不要直接改 `src/prompts/` 里的条目来复用这些脚本**：它们按当时的条目编号和文本匹配，
库里的条目已经重排、合并、改写过，再跑会改错内容。

现在的内容改动流程见 [docs/content.md](../../docs/content.md) 的「新增一条提示词」。
