# 站点细节

## 功能细节

- **分类导航** — 7 个分区 / 49 个分类，侧栏带分区与条目计数，当前项带 `aria-current`，悬停显示分类说明；全部、收藏、自定义三个固定入口保留图标，普通分类只显示文字
- **滚动接续** — 各页滚到底自动翻页（尾部接线插在视口边缘之外，不会顶走滚动位置）；`IntersectionObserver` 不可用或键盘操作时用「再显示」按钮手动兜底
- **全库目录 + 随机卡片流** — 「全部提示词」页首列出全部分类（按分区分组，名称＋条数），点进对应分类页；下面是随机顺序的提示词卡片，「换一批」重排。随机序按条目 id 与种子散列，同一副种子下顺序固定（翻页、收藏都不会让卡片跳位），换种子即换一副顺序；分类页、收藏页与搜索结果仍按库内顺序
- **搜索** — 全局搜索：一开始输入就退出当前分类，在全部条目的标题、正文、简洁表达、标签、分类名与备注里匹配并高亮；搜索结果一律按相关度排序（不被「按复制次数」盖住，否则最像的那条会被按复制次数排到后面）；清空搜索后停在「全部提示词」，点分类或收藏入口则清掉搜索词；输入防抖 120ms；`/` 或 `Ctrl/⌘+K` 聚焦，`Esc` 清空
- **一键复制** — 简洁条目只显示一个版本；确有详略差异的条目显示「简洁表达」和「详细表达」，各带独立复制按钮
- **复制设置** — 复制时可自动套用两类增强：在提示词前加任务命令（`/loop` 等四个常用命令，也可自定义，用途依据[官方命令参考](https://code.claude.com/docs/en/commands)），或从「工作指令块」分类选一个指令块追加到尾部；自定义指令框在选「自定义…」时出现，其内容与库存块可互换替换，切换不影响已填内容；多选版的勾选数据会自动回退为单选第一个；保存在本机
- **收藏** — 本地保存，侧栏「我的收藏」筛选，计数实时更新
- **复制次数** — 本地记录，卡片上显示「已复制 N 次」；工具栏右侧的「按复制次数排列」在浏览时（全部、收藏、分类页）可用，开关状态记在本机；「全部提示词」页开着它时**整库**按复制次数从多到少排列（不是只重排眼前这批随机卡片），随机卡片流的「换一批」按钮暂时隐藏；搜索时结果按相关度排，这个开关不参与，按钮的提示文字会写明
- **分享链接** — 卡片上的链接按钮复制 `#<稳定 id>` 地址，打开后直接跳到该条所在的分类并高亮定位（超出首屏的条目会自动扩展开示范围）；链接里的 id 找不到（条目被删、链接过期）会提示「链接可能已失效」，不会静默停在首页
- **自定义** — 自行添加提示词（弹窗里可填「所属分类」：留空放进「我的自定义」，填新名字就自建一个分类，已有的自建分类会作为候选列出），存入浏览器本地；保存或导入后自动定位到该条目；自建分类不能与库内分类同名（同名会被收进「我的自定义」），自建条目也不会占用库内条目 id
- **完整正文** — 所有版本均直接完整显示，不需要点击展开
- **键盘操作** — 卡片按行优先排布（先左右排满一行，再往下换行），`↑↓` 在行与行之间上下移动、`←→` 在同一行内左右移动、`C` 复制、`F` 收藏 / 取消收藏、`?` 打开「关于」面板（内含站点说明、开发者信息、主站链接、许可信息与快捷键清单）、`Esc` 关闭弹层 / 收起面板 / 清空搜索；弹窗内焦点被困住，关闭后焦点归位；滚动自动接续会重画网格，重画后焦点与选中态仍留在原来那张卡片上
- **明暗主题** — 默认暗色，手动切换并记忆；两套主题的次要文字对比度均 ≥ 4.5:1
- **中英文切换** — 顶栏「EN / 中文」按钮切换界面语言，默认中文，选择记在本机。中文是源文案，英文是并列的一份：界面文案在 `src/assets/i18n.js`（键即中文原文，缺键回退中文），条目与分类的英文译文在 `src/i18n/en/`（一个分类一份 JSON，按条目 id 归属），分区名在 `src/i18n/sections.json`，构建时合并进页面数据 `data.en`。卡片、侧栏、分类名、标签、复制与导出都随语言切换，搜索按当前语言的字段匹配；用户自建内容保持原文。404 页同样跟随语言，页面自带的语言按钮可直接切换
- **响应式** — 桌面侧栏 + 内容区，手机单栏 + 抽屉导航（带遮罩与 Esc 关闭），无横向溢出；手机首屏另做减负：统计面板收成一行细条，「新建」降一档为描边按钮，第一张提示词卡片不用先滚过一整屏介绍就能露头
- **404 页面** — 站点自带 404：沿用首页的品牌标识与明暗主题，给出回首页按钮，并说明「/ 搜索」与「#条目 id 定位」两种用法；页面主题脚本与首页是同一段，nginx 的 CSP 哈希两页共用；404 的语言切换走外部脚本 `assets/404.js`，不新增内联脚本、不占 CSP 哈希
- **导入 / 导出** — 工具栏「导入 / 导出」面板：收藏导出 Markdown 或 JSON，自定义导出 Markdown 或 JSON（文件名带日期，重复导出不覆盖旧文件）；导入分「导入收藏」「导入自定义」两个按钮，各认各的导出文件、选错提示换按钮且不会导入——导入收藏支持 JSON（含裸数组等宽松格式）与 Markdown，库内条目按 id 恢复收藏，其余转入自定义并保留收藏标记；导入自定义只收自定义条目（JSON 或 Markdown），不动收藏；重复导入自动跳过已有条目；自建条目不会占用库内分类名，避免混入官方分类；导出的是原始正文，不含复制设置里的任务命令与指令块

## 质量约定

- **对比度**：正文 ≥ 7:1，次要文字 ≥ 4.5:1（WCAG AA），深浅两套主题都已核验
- **转义**：所有内容先转义再渲染；高亮在原文上定位后逐段转义，不会破坏 HTML 实体
- **无障碍**：语义化标题层级（h1 → h3）、`aria-live` 结果计数、焦点可见、跳转到主内容链接、`prefers-reduced-motion` 支持；弹窗打开时全局快捷键不误触背景，关闭后焦点归位
- **弹窗隔离**：弹窗打开时页面其余部分置 `inert`，移出键盘顺序与读屏导航，关闭后恢复并把焦点交还给触发按钮
- **移动抽屉**：关闭时用 `inert` + `aria-hidden` 移出键盘与读屏导航，打开时抽屉标记为模态对话框（`role="dialog"` + `aria-modal`），背景（顶栏、引导区、内容区）置 `inert`，焦点进入抽屉，关闭后回到菜单按钮
- **缓存**：静态资源引用带内容哈希版本号（`app.js?v=<hash>`），线上不会命中旧缓存
- **CSP 自洽**：主题引导脚本只有一段，首页与 404 页共用；`pytest` 里守着「脚本 sha256 哈希 == nginx.conf 里放行的哈希」，改了脚本忘了改 CSP 会被测试拦下
- **实测**：Chrome Lighthouse（桌面端）无障碍 / 最佳实践 / SEO / 智能体浏览四项均为 100，控制台无报错

## 构建备注

- 解析器对代码块做了 fence 感知：正文里的 `## ` 不会被误判成新条目。三个内容审计脚本共用 `build.py` 的解析规则（`_tools/promptlib.py`），审计看到的条目就是构建时看到的条目；中英文切换另由 `_tools/i18n_audit.py` 单独巡检
- 在 Windows 的 Git Bash / Windows Terminal 里，`build.py` 会自动把输出切到 UTF-8，中文不会显示成乱码；其他终端保持系统默认编码
- 审计脚本（`_tools/*.py`）与 `build.py` 共用 `console_utf8.py`，在 Git Bash / Windows Terminal / VSCode 终端下中文输出不再乱码
- 分享预览图 `dist/assets/og.png` 在构建时按库里的真实条数重画（需要 Pillow；缺失时自动沿用 `src/assets/og.png` 里的静态图，不影响构建）
- 本地预览（`python build.py --serve`）与线上 nginx 的行为对齐：未知路径回站点自带的 `404.html`，端口 8777 已被占用时直接提示退出（Windows 上两个服务器可以同时监听同一端口，表现为「改了 dist 刷新还是旧页面」）
- 仓库里不写死任何本机绝对路径：日志目录走 `PROMPT_LIB_LOGDIR` 环境变量或 `_tools/local_config.json`（见 [audit.md](audit.md)）
- CI（`.github/workflows/ci.yml`）在每次推送与 PR 上跑 `build.py --check`、`pytest`、`build.py`、四份文案审计、产物哈希自检与 `dist/` 同步检查，并上传 `dist/` 构建产物

## 部署产物

`dist/` 目录整体上传到静态根目录即可，纯静态、无后端。产物包含：

| 文件 | 说明 |
| --- | --- |
| `index.html` | 单页，数据内联（无需 fetch，`file://` 直接可用） |
| `404.html` | 404 页面，静态托管下任意路径都有落点 |
| `assets/style.css` `assets/app.js` | 引用带内容哈希版本号 |
| `assets/i18n.js` `assets/404.js` | 界面英文文案字典与 404 页语言切换 |
| `assets/og.png` `assets/icon-180.png` `assets/favicon.ico` | 分享预览图与站点图标 |
| `robots.txt` | 指向 sitemap |
| `sitemap.xml` | 单页站点，`lastmod` 随构建日期更新 |

需要保留的路由：仅 `/` 一个页面，无后端接口。完整部署步骤见 [deploy/README.md](../deploy/README.md)。
